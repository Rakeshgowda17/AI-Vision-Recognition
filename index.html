Project Features

✋ Hand Recognition

Detects hands in real time using MediaPipe hand landmark detection.

🔢 Finger Counting

Recognizes the number of raised fingers from 0 to 5.

🤟 Gesture Recognition

Identifies common hand gestures such as Peace and other gestures.

📦 Object Detection

Detects objects such as people, bottles, mobile phones and other objects.

How It Works

01. Webcam Input

The application captures live video from the computer webcam.

02. Hand Detection

MediaPipe detects hand landmarks and analyzes finger positions.

03. Gesture Recognition

The system analyzes the hand landmarks to identify gestures and count fingers.

04. Object Detection

YOLO-based object detection identifies objects visible through the webcam.
